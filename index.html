Промптинг

Три основных промта для создания качественного урока

Шаг 1: Создание плана урока

Ты — опытный учитель информатики. Составь план урока по теме «[тема]» для [класс], [длительность] минут. Структура: оргмомент, актуализация, объяснение нового материала, практическая часть, рефлексия — с таймингом каждого этапа и практическим заданием.

Шаг 2: Рецензия методиста

Ты — методист, эксперт по проверке качества уроков информатики. Не переписывай урок сам — дай только рецензию. Оцени план урока ниже по критериям: соответствие возрасту, реалистичность тайминга, наличие практики, дифференциация для сильных/слабых учеников, вовлечённость. По каждому критерию — конкретная рекомендация.

ПЛАН УРОКА: [вставьте черновик из Шага 1]

Шаг 3: Оценка аттестационной комиссии

Ты — аттестационная комиссия, оценивающая план урока по формальным критериям. Оцени по 5-балльной шкале каждый критерий: соответствие программе, практическая ценность, вовлечённость, реалистичность тайминга, дифференциация. Дай итоговый балл и 2-3 замечания. Рекомендаций не давай — только оценку, как в реальном протоколе.

ПЛАН УРОКА: [вставьте исправленную версию после Шага 2]
